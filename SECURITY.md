# Security Policy

## Поддерживаемые версии

До первого стабильного выпуска поддерживается только последняя версия `0.x`.

| Версия  | Поддерживается |
|---------|----------------|
| `0.1.x` | Да             |
| `< 0.1` | Нет            |

## Сообщение об уязвимости

Не создавайте публичный issue с описанием уязвимости, exploit или секретами.

1. Откройте вкладку **Security** репозитория.
2. Выберите **Report a vulnerability** и создайте приватный отчёт.
3. Укажите затронутую версию, влияние, шаги воспроизведения и возможное исправление.

Если private vulnerability reporting ещё не включён, сообщите владельцу через профиль GitHub, не раскрывая технические
детали публично.

Получение отчёта будет подтверждено по возможности в течение 7 дней. Срок исправления зависит от критичности. Публикация
деталей согласуется после выпуска исправления.

## Известное ограничение `0.1.x`

Аутентификация и авторизация ещё не реализованы: Bearer JWT присутствует только в OpenAPI contract. Версию `0.1.x`
следует запускать исключительно в доверенном локальном/тестовом окружении.
