# Политика безопасности

## Поддерживаемые версии

| Версия | Поддержка |
| ------ | --------- |
| 1.2.x  | Да        |
| 1.1.x  | Да        |
| 1.0.x  | Да        |
| < 1.0  | Нет       |

## Граница безопасной эксплуатации

Configurator v1 поддерживает только локальные пакеты для Windows и macOS с Docker Desktop. Шлюз должен оставаться на
`127.0.0.1:8080`; серверная часть, PostgreSQL и MinIO не публикуются из внутренней сети Docker. Работа через локальную
сеть или интернет, серверное развёртывание и одновременная работа нескольких пользователей не входят в поддерживаемый
контур безопасности.

В OpenAPI объявлены операции регистрации, входа и схема Bearer JWT, но действующая аутентификация и авторизация в
приложении пока не реализованы. Эта декларация не защищает REST API. Не изменяйте локальную привязку порта и не
развёртывайте текущую версию на доступном другим пользователям узле.

Пакет содержит локальные учётные данные инфраструктуры, а резервные копии не зашифрованы. Храните распакованный пакет
и копии в каталоге текущего пользователя, не загружайте их в открытые хранилища и не прикладывайте к публичным задачам.

## Сообщение об уязвимости

Не создавайте публичную задачу. Используйте
[приватное сообщение об уязвимости GitHub](https://github.com/eltgm/configurator-root/security/advisories/new) и укажите:

- затронутую версию и операционную систему;
- точные шаги воспроизведения и ожидаемое влияние;
- минимальный пример без настоящих секретов или персональных данных;
- известные способы временно избежать проблемы.

Получение отчёта подтверждается в течение семи дней. Состояние проверки, план исправления и согласованное раскрытие
обсуждаются в закрытом уведомлении GitHub. Не публикуйте сведения до выпуска исправления.

## Зависимости и происхождение поставки

Dependabot отслеживает npm, Gradle, Docker и GitHub Actions. Подготовка выпуска использует минимальные разрешения,
закреплённые полные хеши внешних действий, образы по дайджестам, перечни состава ПО, сведения о происхождении и
аттестации GitHub OIDC. Перед установкой пользователь должен проверить `SHA256SUMS`, а при необходимости — аттестации.
