CONFIGURATOR — ЛОКАЛЬНАЯ PREVIEW-ВЕРСИЯ

Требование: установленный Docker Desktop и доступ в интернет при первом запуске и обновлении.

Подробная подготовка Windows 10/11, включая BIOS/UEFI, WSL 2 и Docker Desktop:
https://github.com/eltgm/configurator-root/blob/master/docs/user/WINDOWS_DOCKER_DESKTOP_SETUP.md

1. Распакуйте весь архив в обычную пользовательскую папку.
2. Запустите Start двойным кликом.
3. Дождитесь сообщения о готовности — браузер откроется автоматически.

Доступные действия:
- Start — запустить приложение;
- Stop — остановить приложение без удаления данных;
- Update — создать backup и загрузить новые stable-образы;
- Backup — сохранить базу данных и изображения;
- Restore — восстановить выбранный backup.

Backups находятся в папке backups и НЕ зашифрованы. Храните их в доверенном месте. Restore поддерживает только
backups, созданные этим пакетом Configurator. Не используйте неизвестные PostgreSQL dump-файлы.

Приложение доступно только на http://127.0.0.1:8080. Не меняйте адрес на 0.0.0.0 и не публикуйте приложение в локальную
или публичную сеть: runtime-аутентификация пока не реализована.

Если Docker Desktop запускается впервые, самостоятельно примите его лицензионное соглашение. На macOS при системном
предупреждении используйте правый клик по файлу Start.command → «Открыть». Не отключайте Gatekeeper.

Подробные сообщения и диагностика сохраняются в папке logs.
