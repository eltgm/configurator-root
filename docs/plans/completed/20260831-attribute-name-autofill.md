# Автозаполнение системного имени атрибута

Статус: выполнено 2026-08-31. План подтверждён пользователем перед реализацией.
Ветка: `feature/CON1-141`, создана от `develop` и переименована из `codex/attribute-name-autofill`.

## Согласованное поведение

- Общая форма каталога и страницы типов: название первым, с начальным фокусом.
- Новые атрибуты: мгновенная транслитерация русского алфавита в ASCII snake_case.
- Латиница, camelCase, аббревиатуры, цифры и смешанные названия поддерживаются.
- Любое ручное изменение системного имени, включая очистку, отключает автозаполнение.
  Фокус и blur его не отключают. Ручные значения не нормализуются сверх прежнего trim.
- Сохранённое имя при редактировании автоматически не меняется.
- «Заполнять из названия» явно заменяет имя и возвращает автоматический режим.
- Пустой результат остаётся пустым; имя длиннее 255 символов не обрезается и проверяется формой.
- Коллизии обрабатываются существующим серверным 409 без генерации суффиксов.
- Правила русской транслитерации фиксированы: ё→yo, й/ы→y, х→kh, щ→shch, ь/ъ удаляются.

## Реализация

`suggestAttributeName` выполняет Unicode NFC normalization, выделяет границы camelCase/аббревиатур,
транслитерирует русский алфавит и формирует ASCII snake_case. Ограниченное регулярное выражение
разделяет `HTTPVersion`, сохраняя короткие обозначения единиц вроде `MHz`. Диакритика латинских
букв удаляется после транслитерации, чтобы сохранить различие `е/ё` и `и/й`.

Режим хранится в ref формы, отдельно от dirty/touched. Изменение названия синхронно обновляет `name`
через RHF `setValue`; ручное изменение отключает автоматику. Таймеров, новых зависимостей, HTTP-запросов
и глобального состояния нет. Неизменившееся предложение повторно не записывается.

Проверки выявили и помогли исправить два дефекта доступности общей формы:

- Mantine focus trap требует `data-autofocus` для надёжного начального фокуса на названии.
- Кнопке закрытия добавлено локализованное доступное имя; текст ошибки в тёмной теме использует
  `--mantine-color-red-4` только внутри формы. Общая тема не изменена.

Выбор цвета задан через атрибут темы: визуальная проверка собранной SPA обнаружила некорректное
преобразование `light-dark()` сборщиком внутри CSS-переменной. Итоговые светлые/тёмные снимки ошибок
проверены вручную; красный цвет, рамка и текст ошибки сохраняются.

## Производительность

Локальный microbenchmark в Node.js 24.10.0: 10 000 прогревочных вызовов, затем 100 000 измеряемых.
Строка из 255 символов смешанного русского/латинского текста — около 14 мкс на вызов;
255 букв `Щ` с расширением результата до 1020 символов — около 23 мкс.
Это оценка стоимости функции на текущем компьютере, не измерение задержки отрисовки браузера.
Для типичного ввода debounce не нужен; слишком длинный результат блокируется текущей валидацией.
