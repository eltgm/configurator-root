# План 9.16 — галерея изображений компонента

## Цель

Добавить в карточку компонента полное управление галереей: просмотр, загрузку, безвозвратное удаление и атомарное
изменение порядка. Интерфейс должен одинаково работать мышью, клавиатурой и на телефоне от 360 px.

## Границы

- OpenAPI, backend, Flyway, jOOQ и generated API не меняются.
- Используются существующие list/upload/delete/reorder endpoints изображений.
- Загружается один JPEG, PNG или WebP размером до 10 МиБ; новое изображение добавляется в конец.
- Архивный компонент сохраняет галерею только для чтения.
- Перестановка выполняется кнопками «раньше/позже» без drag-and-drop.
- Локальный `testcontainers.properties` не входит в изменения.

## Реализация

1. Актуализировать детальные требования 9.16.
2. Добавить domain-scoped query key и отдельные TanStack Query hooks галереи.
3. Добавить чистые функции проверки файла, сортировки и перестановки с unit-тестами.
4. Реализовать адаптивную галерею с явной загрузкой, preview и подтверждением безвозвратного удаления.
5. Реализовать локальный черновик порядка с Save/Cancel и отправкой полного массива `imageIds`.
6. Синхронизировать gallery/detail cache и инвалидировать каталоги только затронутой предметной области.
7. Добавить русскую/английскую локализацию, component/MSW и Playwright tests.
