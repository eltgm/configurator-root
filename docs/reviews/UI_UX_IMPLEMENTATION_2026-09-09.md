## Контракты и архитектура

- OpenAPI изменён совместимо: необязательные `attributes` в ответах подбора; необязательные `name`, `sortBy`,
  `sortDirection` в списке конфигураций. Старый порядок по дате создания и ID убыванию сохранён по умолчанию.
- Frontend SDK и backend DTO регенерированы штатно. Generated-файлы вручную не редактировались.
- Поиск выполняется в repository после ограничений области/владельца, до пагинации. Сортировка выбирает поле из
  разрешённого набора, имеет стабильный дополнительный порядок по ID. Символы SQL LIKE ищутся буквально.
- Схема БД, Flyway, security, delivery-контракты и правила совместимости/резервирования не менялись.
- Сохранена цепочка controller → facade → service → port → persistence. Новые характеристики используют существующую
  загрузку компонентов; дополнительных запросов из карточек списка не добавлено. Полные данные запрашивает только
  открытый быстрый просмотр.
- Формы не сохраняются между запусками. Автоматический черновик сборки продолжает работать как прежде.

томами; пользовательские БД не использовались. После проверки тестовый Compose-контур и его тома удалены. Первый Gradle-прогон упал из-за выключенного Docker, после запуска
Docker полный и внешний контуры прошли. На промежуточных UI-прогонах исправлены несовпадения тестовых ожиданий,
прокрутка к подбору, закрытие панели на breakpoint и отсутствовавшие доступные имена кнопок закрытия.

На момент первоначальной реализации полный `npm audit` сообщал о 5 уязвимостях **dev-зависимостей** (4 high, 1
moderate: цепочка Hey API/js-yaml и colord). В release-подготовке v1.3.1 override `js-yaml` обновлён до 4.3.2,
Stylelint — до 17.15.0, lockfile пересоздан; повторный `npm ci` и `npm audit --audit-level=high` показали 0
уязвимостей.

## Ограничения ручной приёмки

- Axe и автоматическая клавиатурная проверка не заменяют VoiceOver/NVDA и проверку на физических телефонах; эти
  проверки не выполнялись. Полевые Core Web Vitals не измерялись.
- Trusted-local Windows/macOS scope сохранён. Runtime-аутентификация и авторизация по-прежнему отсутствуют;
  UI-исправления не разрешают LAN/public/server deployment.
- Изменённые baseline-снимки просмотрены в сравнении с HEAD. Чёрные фотографии — существующие тестовые изображения
  mock API, а не дефект загрузки пользовательских фотографий.
