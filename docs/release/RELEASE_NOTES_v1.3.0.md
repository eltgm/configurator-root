# Configurator v1.3.0

`v1.3.0` добавляет количество экземпляров и опциональный учёт остатков в каталог и сохранённые конфигурации. Релиз
поддерживается только как trusted-local пакет Windows/macOS с Docker Desktop и gateway на `127.0.0.1:8080`; это не
LAN, server или multi-user deployment.

## Что нового

- Для каждого компонента задаётся общее количество; каталог и карточка показывают, сколько экземпляров занято и
  доступно.
- В сборку можно добавить несколько моделей одного типа и указать количество каждой модели. Повторное добавление
  модели увеличивает количество.
- При сохранении или редактировании можно включить «Учитывать количество компонентов». Сервер атомарно резервирует
  остатки и отклоняет всю операцию, если хотя бы одной позиции недостаточно.
- Список конфигураций фильтруется по режиму учёта. Удаление конфигурации или выключение режима освобождает остатки;
  копия создаётся без резервирования до явного включения пользователем.
- API принимает `components: [{ componentId, quantity }]` и возвращает количества. Старый `componentIds` пока
  поддерживается как deprecated-вход с количеством 1.
- Обновлены пользовательская и разработческая документация, доступные имена пагинации и visual baselines.

## Перед обновлением

Создайте Backup в текущем пакете и используйте новый архив `v1.3.0` целиком. Flyway V10 добавляет только новые поля:
существующие компоненты получают общее количество 0, существующие конфигурации — количество 1 для каждой модели и
выключенный учёт остатков. Поэтому после обновления сначала задайте реальные общие количества компонентов, затем
явно включите учёт в нужных конфигурациях.

Черновики формата v1 читаются автоматически с количеством 1 и при следующем изменении сохраняются в формате v2.
JSON-экспорт теперь имеет `schemaVersion: 2`; импорт по-прежнему не поддерживается. Не изменяйте историю Flyway и не
перемещайте существующие теги или exact images.

Проверьте архив и происхождение перед запуском:

```bash
gh attestation verify configurator-macos-v1.3.0.tar.gz -R eltgm/configurator-root
gh attestation verify oci://ghcr.io/eltgm/configurator-app:1.3.0 -R eltgm/configurator-root
```

Полная установка, Update, Backup и Restore описаны в [`LOCAL_DELIVERY.md`](LOCAL_DELIVERY.md).
