# Configurator v1.0.0

Первый стабильный релиз Configurator поставляется как локальное приложение для Windows и macOS. Пользователю нужны
Docker Desktop, интернет для первого запуска и полностью распакованный архив; JDK, Node.js и Git не требуются.

## Что входит

- управление предметными областями, типами, атрибутами, компонентами и изображениями;
- ручная и автоматическая совместимость, граф и объяснение результата;
- прямой, транзитивный, множественный поиск и пересечения;
- сохранение, копирование и JSON-экспорт конфигураций;
- адаптивный web-интерфейс со светлой, тёмной и системной темами;
- Start, Stop, Update, Backup и Restore для Windows/macOS.

## Установка

1. Скачайте `configurator-windows-v1.0.0.zip` или `configurator-macos-v1.0.0.tar.gz` из GitHub Release.
2. Проверьте архив по `SHA256SUMS`.
3. Полностью распакуйте папку `Configurator` в каталог с правом записи.
4. Запустите `Start.cmd` или `Start.command` и дождитесь открытия <http://127.0.0.1:8080>.

Update сначала создаёт backup, затем получает образы канала `stable` и проверяет readiness. Restore проверяет backup и
создаёт страховочную копию текущего состояния. Backups не зашифрованы.

## Проверка происхождения

```bash
gh attestation verify configurator-windows-v1.0.0.zip -R eltgm/configurator-root
gh attestation verify oci://ghcr.io/eltgm/configurator-app:1.0.0 -R eltgm/configurator-root
```

Имена и immutable digests образов находятся в `IMAGE_DIGESTS`; единый список checksum — в `SHA256SUMS`.

## Граница поддержки

Релиз предназначен для одного доверенного пользователя и только для локального loopback-доступа. Не меняйте привязку
`127.0.0.1:8080` и не публикуйте приложение в LAN или интернет. Серверное развёртывание не поддерживается. Для данных,
созданных до `v1.0.0`, при необходимости используйте чистую переустановку.
