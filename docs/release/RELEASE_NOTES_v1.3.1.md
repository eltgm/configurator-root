# Configurator v1.3.1

`v1.3.1` улучшает ежедневную работу с каталогом, конфигурациями и сборкой: ускоряет поиск, сохраняет контекст
пользователя и делает интерфейс удобнее на телефоне. Релиз поддерживается только как trusted-local пакет Windows/macOS
с Docker Desktop и gateway на `127.0.0.1:8080`; это не LAN, server или multi-user deployment.

## Что нового

- Список конфигураций теперь ищет по имени на сервере и поддерживает сортировку без потери фильтра учёта остатков,
  области и пагинации.
- Карточка кандидата в конфигураторе показывает три основные характеристики, а полный быстрый просмотр открывается
  без перехода со страницы. Длинные составы конфигураций раскрываются по запросу.
- Фильтры каталога и подбора сохраняются при переходах и изменении состава. На узком экране сначала видны доступные
  варианты, затем текущая сборка; заблокированные варианты можно раскрыть полностью.
- Добавлена страница «Помощь» с пятью шагами подготовки каталога и сборки. Формы предупреждают о несохранённых
  изменениях, а контекстные ошибки больше не дублируются уведомлениями.
- Мобильная навигация открывает полный раздел настроек. Touch-элементы имеют минимальную область 44 CSS px, а
  доступные имена и активные состояния навигации уточнены.
- Для Windows добавлено отдельное пошаговое руководство: включение виртуализации, WSL 2 и установка Docker Desktop.

## Совместимость и обновление

Схема БД, Flyway-миграции, формат backup v1 и delivery-контракты не менялись. Установите новый архив `v1.3.1` целиком
или выполните штатный `Update` из существующего пакета после обязательного Backup. API-изменения совместимы: новые
параметры поиска и сортировки конфигураций, а также характеристики кандидатов необязательны.

Проверьте архив и происхождение перед запуском:

```bash
gh attestation verify configurator-macos-v1.3.1.tar.gz -R eltgm/configurator-root
gh attestation verify oci://ghcr.io/eltgm/configurator-app:1.3.1 -R eltgm/configurator-root
```

Полная установка, Update, Backup и Restore описаны в [`LOCAL_DELIVERY.md`](LOCAL_DELIVERY.md).
