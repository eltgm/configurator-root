# Configurator v1.1.0

Minor release локального Configurator для Windows и macOS. Пользователю нужны Docker Desktop, интернет для первого
запуска и полностью распакованный архив; JDK, Node.js и Git не требуются.

## Что нового

- **Переиспользуемый каталог атрибутов.** Атрибут создаётся в пределах предметной области, подключается к нескольким
  типам компонентов и сохраняет независимые настройки обязательности и порядка для каждой связи. В интерфейсе добавлен
  отдельный раздел управления каталогом и выбор существующего атрибута при настройке типа.
- **Интуитивная совместимость сборки.** Конфигуратор предлагает кандидатов по отношениям с текущей сборкой, отдельно
  объясняет заблокированные варианты и допускает сохранение связной конфигурации без искусственных отношений между
  каждой парой компонентов; применимое несовпадение автоматического правила остаётся блокирующим.

## Обновление и установка

Для обновления существующего пакета используйте `Update`: перед загрузкой `stable` images он обязательно создаёт
backup и затем проверяет readiness. Миграция Flyway `V7` переводит определения атрибутов `v1.0.0` в доменный каталог с
сохранением идентификаторов и связей. Перед обновлением важных данных сохраните отдельную копию backup.

Для чистой установки скачайте `configurator-windows-v1.1.0.zip` или `configurator-macos-v1.1.0.tar.gz`, проверьте
архив по `SHA256SUMS`, полностью распакуйте папку `Configurator` и запустите `Start.cmd` или `Start.command`.

## Проверка происхождения

```bash
gh attestation verify configurator-windows-v1.1.0.zip -R eltgm/configurator-root
gh attestation verify oci://ghcr.io/eltgm/configurator-app:1.1.0 -R eltgm/configurator-root
```

Имена и immutable digests образов находятся в `IMAGE_DIGESTS`; единый список checksum — в `SHA256SUMS`.

## Граница поддержки

Релиз предназначен для одного доверенного пользователя и только для локального loopback-доступа. Не меняйте привязку
`127.0.0.1:8080` и не публикуйте приложение в LAN или интернет. Runtime-аутентификация и авторизация не реализованы;
серверное и multi-user развёртывание не поддерживается. Backups не зашифрованы.
