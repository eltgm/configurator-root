# Configurator v1.2.0

`v1.2.0` расширяет каталог компонентов, делает очистку изображений устойчивой к сбоям и усиливает целостность данных
предметной области. Релиз поддерживается только как trusted-local пакет Windows/macOS с Docker Desktop и gateway на
`127.0.0.1:8080`; это не LAN, server или multi-user deployment.

## Что нового

- Системное имя атрибута теперь уникально в области без учёта регистра. При обновлении V8 объединяет только
  совместимые дубликаты и сохраняет привязки, значения и правила; конфликт останавливает миграцию без частичных изменений.
- Выбирайте заглавное изображение компонента. Каталог и конфигуратор используют прозрачные PNG-превью до 512 × 512,
  а полное изображение открывается только по запросу.
- Удалённые оригиналы и превью попадают в сохраняемую очередь MinIO: после временного сбоя обработчик повторит очистку
  после восстановления хранилища.
- При удалении области требуется точное подтверждение названия. Существующая конфигурация блокирует действие с
  `409 DOMAIN_HAS_CONFIGURATIONS`, поэтому данные конфигураций не удаляются каскадно.
- Редактор сохранённой конфигурации лучше ведёт замену компонентов: сохраняет фокус и контекст, сбрасывает устаревшие
  фильтры и остаётся пригодным для narrow layouts.

## Перед обновлением

Создайте backup в текущем пакете и используйте новый архив `v1.2.0` целиком. V8 выполняет миграцию данных и может
остановиться, если ранее были созданы несовместимые определения атрибутов с одинаковым именем. В этом случае база не
изменена: исправьте указанные в ошибке данные, затем повторите запуск. Не редактируйте историю Flyway и не удаляйте
старые exact images или теги.

Проверьте архив и происхождение перед запуском:

```bash
gh attestation verify configurator-macos-v1.2.0.tar.gz -R eltgm/configurator-root
gh attestation verify oci://ghcr.io/eltgm/configurator-app:1.2.0 -R eltgm/configurator-root
```

Полная установка, Update, Backup и Restore описаны в [`LOCAL_DELIVERY.md`](LOCAL_DELIVERY.md).
